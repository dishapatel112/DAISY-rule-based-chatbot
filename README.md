# DAISY Assistant

## Overview
DAISY (Disha's AI Smart and Intelligent System) is a rule-based chatbot developed using Python. The chatbot interacts with users through predefined commands and responses, demonstrating fundamental Artificial Intelligence concepts such as decision-making, control flow, and conversational logic.

This project was built as a hands-on exercise to understand how rule-based systems work before moving on to more advanced AI concepts like machine learning and natural language processing.

## Features
- Greeting responses
- Personalized user interaction
- Motivation generator
- Joke generator
- Study tips generator
- AI quiz with scoring
- AI learning roadmap (Beginner / Intermediate / Advanced)
- Current date and time display
- Mood detection
- AI and Python FAQs
- Conversation counter
- Help menu
- Exit commands


## Commands Supported

| Command | What it does |
|---|---|
| `hi` / `hello` | Greets the user |
| `good morning` / `good night` / `good evening` | Time-based greetings |
| `happy` / `sad` / `bored` / `tired` / `stress` | Mood detection and response |
| `joke` | Tells a random joke |
| `motivate me` | Gives a motivational quote |
| `study tip` | Shares a learning technique |
| `quiz` | Starts a 5-question AI quiz |
| `roadmap` | Shows the AI learning path by level |
| `time` | Shows the current time |
| `date` | Shows the current date |
| `what is ai` / `what is ml` / `what is python` | Quick explanations |
| `count` | Shows the conversation message count |
| `about` | Tells more about DAISY |
| `help` | Shows the help menu |
| `bye` | Ends the session |
